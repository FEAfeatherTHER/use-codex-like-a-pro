# 虚构资料包：仅用于教学

以下资料由本示例构造，不是实际厂商文档。所有日期、版本和能力声明均为虚构。

## S1：Alpha 使用说明 v1

- 资料日期：2026-10-20（演示）
- 可用阶段：首次任务起
- 原文内容：Alpha 支持 CSV 导入和本地 HTML 报告导出；完整流程可在断开网络后执行。
- 维护说明：升级时替换可执行文件并核对配置，共两步。
- 未说明：性能、跨平台可用性和维护耗时。

## S2：Beta 使用说明 v1

- 资料日期：2026-10-20（演示）
- 可用阶段：首次任务起
- 原文内容：Beta 支持 CSV 导入、HTML 和 PDF 报告导出。
- 维护说明：升级时替换程序、更新模板并核对配置，共三步。
- 未说明：断网运行能力、实际维护耗时和性能。

## S3：Beta 离线部署补充 v1

- 资料日期：2026-10-22（演示）
- 可用阶段：第四阶段；第三阶段尚未获得
- 原文内容：Beta 的离线部署包支持断网后的 CSV 导入与 HTML、PDF 导出，首次安装包须预先获取。
- 未说明：维护耗时、性能，以及尚未列出的其他能力。

S2 没有说明离线能力，不等于证明 Beta 不支持离线。S3 只能支持其明确描述的流程，不能推断全部功能可离线。
